# carla-sarda

Web del Mas: lloguer vacacional que porten la Carla i la seva germana.

`index.html` és un primer esborrany per ensenyar-li. Textos, dades i fotos són provisionals: les dades que falten surten marcades amb un guionet subratllat.

La identitat gràfica (colors i tipografia) està definida a dalt de tot del `<style>`, a `:root`. Quan arribi la del dissenyador, es canvia només allà.

Abans de publicar-la de debò, treure `<meta name="robots" content="noindex">`.
